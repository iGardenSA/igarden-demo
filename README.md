# iGarden Smart OS — Live Demo

لوحة تحكم تفاعلية لنظام iGarden Smart OS.

**الموقع الرسمي:** https://igarden.sa
**الديمو الحي:** https://demo.igarden.sa

## المميزات

- لوحة تحكم بـ 10 شاشات تفاعلية
- مراقبة حية لـ 7 حسّاسات (pH, EC, Water Temp, Tank Level, Air Temp, Humidity, Light)
- سيناريوهات تحكم ذكية (Scenario Engine)
- نظام تنبيهات متقدم (Alerts System)
- إدارة الجرعات والمحابس الذكية

## التقنية

- Pure HTML/CSS/JavaScript
- Tajawal + JetBrains Mono fonts
- RTL interface
- Mock data للعرض والتجربة
